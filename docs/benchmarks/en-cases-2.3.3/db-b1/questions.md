# Questions asked before designing

The agent's reply to the prompt, verbatim. It was answered from the experiment's fact sheet (see the experiment README).

---

I have three questions before I start designing. Each answer changes a major decision.

1. **Who is this new user, and what's in their account on first login?** Did they create a brand-new workspace (so it's empty and the dashboard is really a getting-started screen), or were they invited to a team that already has projects and tasks assigned to them? If both happen, which one should I design first?

2. **What does the product actually include?** Please list the core objects and features: for example projects, tasks, boards or lists, due dates, team members, integrations. Also tell me the product name, if it has one. I don't want to put features or page names on the dashboard that the app doesn't have.

3. **Is there an existing brand or design system to follow?** That means colors, type and components, or a DESIGN.md. Also, which market and language is it for (English, global)? If there's none, I'll set a neutral, restrained direction and list it as an assumption.
