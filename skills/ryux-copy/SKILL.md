# ryux-copy: Indonesian copywriting

> ryux.design design rules, version 0.2.0, MIT licensed.
> Apply to indonesian copywriting work before considering it done.

- **RX-C-06** Copy is specific about the action and the benefit; avoid empty clichés and generic CTAs.
- **RX-L-06** Money uses the local Rupiah format (Rp + thousands separators).
- **RX-L-07** Copy is natural Bahasa Indonesia, not a stiff translation from English.
- **RX-H-09** Error recovery: clear message, state the cause, give a concrete way out.
- **RX-N-05** Error messages state the problem plus the fix, near the source; don't blame the user.
