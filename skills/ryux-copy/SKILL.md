# ryux-copy: Indonesian copywriting

> ryux.design design rules, version 0.3.0, MIT licensed.
> Apply to Indonesian copywriting work before considering it done. [Required] rules are a hard gate; the rest
> may be broken only with a written reason.

- **RX-C-06** Copy is specific about the action and the benefit; avoid empty clichés and generic CTAs.
- **RX-H-02** Match the real world: language and ordering follow user habits.
- **RX-L-06** [Required] Money uses the local Rupiah format (Rp + thousands separators).
- **RX-L-07** [Required] Copy is natural Bahasa Indonesia, not a stiff translation from English.
- **RX-H-09** [Required] Error recovery: clear message, state the cause, give a concrete way out.
- **RX-N-05** [Required] Error messages state the problem plus the fix, near the source; don't blame the user.
