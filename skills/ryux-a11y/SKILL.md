# ryux-a11y: Accessibility

> ryux.design design rules, version 0.2.0, MIT licensed.
> Apply to accessibility work before considering it done.

- **RX-H-11** WCAG AA contrast: normal text >= 4.5:1, large text >= 3:1.
- **RX-H-12** Body text >= 12px; touch targets >= 44x44px.
- **RX-H-13** Keyboard focus is visible; focus order is logical.
- **RX-H-14** Complete states (loading/empty/error/success); no overflow; respect safe areas.
