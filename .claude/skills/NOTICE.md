# antislop — catatan vendor

Skill antislop di folder ini **disalin (vendored)** dari paket npm `antislop-ai`
supaya **versi terkunci** dan ikut saat repo di-clone (sesuai `CLAUDE.md`).

- **Versi:** 3.2.13 (lihat [`antislop/VERSION`](./antislop/VERSION))
- **Lisensi:** MIT — lihat [`LICENSE`](./LICENSE)
- **Sumber:** https://github.com/miqdadbadjuber/anti-slop
- **Penulis:** Miqdad Badjuber (antislop)

Skill yang disertakan: `antislop` (inti), `antislop-ui`, `antislop-copywriting`,
`antislop-human` (termasuk `contrast-check.py`), `antislop-layoutmobile`, `antislop-code`.

**Memperbarui:** jalankan `npx antislop-ai` di terminal interaktif, salin ulang folder skill
ke sini, lalu naikkan nomor versi di atas dan di `antislop/VERSION`.
